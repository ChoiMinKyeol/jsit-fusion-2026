공간정보 영상 전처리 체험실 고교 공간정보 수업용

원격탐사 원시 항공·위성 영상의 품질 개선 및 핵심 알고리즘 실습

원본 영상 (256×256) 저대비/어두움
원본 명암 히스토그램 0~255
전처리 결과 영상 Step: 0
결과 명암 히스토그램 0~255

적용된 처리 순서 (Sequence Stack)

도구 버튼을 누르면 해당 전처리 알고리즘이 현재 결과 영상에 순차적으로 적용됩니다. 오른쪽 제어판에서 원하는 전처리 기법을 클릭해 보세요.

영상 전처리 알고리즘 단계별 누적 처리

1. 명암도(Grayscale) 변환
2. 밝기 및 명암비(Contrast) 조절
밝기 (Brightness) +0
명암비 (Contrast) 0
3. 히스토그램 균등화 & 이진화
이진화 (Binarization / Thresholding) 임계값: 128
4. 잡음(Noise) 추가 실험
5. 공간 필터링 (Spatial Filtering)
